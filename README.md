# Amazon Clone 🛒

A simple **Amazon homepage clone** built using **HTML and CSS**.
This project recreates the basic layout and design of Amazon's website for learning and practice purposes.

## 📌 Project Overview

This project is a frontend practice project that demonstrates how to create an e-commerce website layout using HTML and CSS.

It includes:

* Amazon-style navigation bar
* Amazon logo
* Delivery location section
* Search bar
* Sign-in and account section
* Returns & Orders section
* Shopping cart
* Navigation panel
* Hero/banner section
* Product/category cards
* Footer with multiple sections
* Responsive design for different screen sizes
* Font Awesome icons

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
* Responsive Web Design

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Make sure all images are in the correct folder.
4. Open `amazon.html` in your web browser.
You can also use **Live Server** in Visual Studio Code for a better development experience.

## 🎨 Features

### Navigation Bar

The navigation bar contains:

* Amazon logo
* Delivery location
* Search bar
* Account & Lists
* Returns & Orders
* Shopping cart

### Product Section

The homepage contains multiple product/category cards with images and "See more" links.

### Hero Section

A large banner image is displayed below the navigation panel with an Amazon-style information message.

### Footer

The footer contains:

* Back to Top
* Get to Know Us
* Make Money with Us
* Amazon Payment Products
* Let Us Help You
* Privacy and Conditions links
* Copyright information

## 📱 Responsive Design

The website has responsive CSS for:

* Desktop
* Tablet
* Mobile devices

The layout automatically adjusts the product cards and navigation elements according to the screen size.
